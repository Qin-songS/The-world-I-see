# The world I see

A public, evolving knowledge graph generated from my Notion Knowledge OS and explored in Obsidian.

- **Notion is the source of truth**
- **Obsidian is the visualization / exploration layer**
- Files marked `generated: true` are generated projections rather than a second knowledge base

The repository is intentionally public so others can inspect how ideas, learning records, topics, and knowledge nodes connect over time.
